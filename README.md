# The Deviant's Shelf

Invite-only catalog. No payment is taken in the app.

## First-run settings

Edit `src/data.js`:

- `memberPin` — what friends type (default `2614`)
- `adminPin` — opens the Desk tab (default `6149`)
- `pay.ownerName`, Venmo, Zelle, Cash App

## Local

```bash
npm install
npm run dev
```

## Notes

Orders live in the browser that placed them. The Desk sees the same tickets only on that device until a shared inbox is wired.

Research use only. Not a drug, supplement, or treatment.
